# Hospital DSA Management System — C++

A university DSA semester project based on the supplied course outline.

## Included topics

- Arrays
- Linear search and binary search
- Selection, bubble and insertion sort
- Singly linked list
- Doubly linked list
- Array stack and linked-list stack
- String reversal and symbol balancing
- Infix/postfix/prefix conversions
- Postfix evaluation
- Array queue, linked queue, circular queue
- Priority queue
- Graph adjacency matrix/list
- BFS and DFS
- Prim and Kruskal MST
- Binary Search Tree and traversals
- Max heap and min heap
- AVL tree
- Hashing: division, multiplication, mid-square, folding
- Collision resolution: linear probing, quadratic probing, separate chaining
- File handling

## VS Code

Open this folder in VS Code.

Compile from the project root:

```bash
g++ -std=c++11 -I src src/main.cpp -o HospitalDSA
```

Run:

```bash
./HospitalDSA
```

Windows:

```powershell
g++ -std=c++11 -I src src/main.cpp -o HospitalDSA.exe
.\HospitalDSA.exe
```

## Dev-C++

Dev-C++ is also fine. Create a Console C++ project, add `src/main.cpp`, and compile with a C++11-capable compiler.

## Important

The data structures are implemented manually for DSA learning. The project does not replace the course structures with `std::stack`, `std::queue`, etc.

## Project theme

The hospital theme is only the application context. The main purpose is to demonstrate the DSA structures and algorithms taught in the course.
