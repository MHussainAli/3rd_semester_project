# DSA Concept Map

| Syllabus area | Project |
|---|---|
| Array | Patient array |
| Linear/Binary Search | Patient search |
| Selection/Bubble/Insertion Sort | Sorting module |
| Singly Linked List | Treatment/history list |
| Doubly Linked List | Medical history list |
| Stack | Array and linked stack |
| Stack Applications | Reversal, balancing, expression conversion/evaluation |
| Queue | Array and linked queues |
| Circular Queue | Circular queue module |
| Priority Queue | Emergency patients |
| Graph | Hospital department network |
| BFS/DFS | Graph traversal |
| Prim/Kruskal | Minimum spanning trees |
| Binary Tree/BST | Tree and patient ID operations |
| Heap | Max/min heap |
| AVL | Balanced search tree |
| Hashing | Four hash functions and three collision methods |
| File Handling | Patient records |
